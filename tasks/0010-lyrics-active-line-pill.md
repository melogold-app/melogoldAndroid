# Синхронный текст: подложка под текущей строкой по размеру строки

Статус: открыто

Те же задания: `melogoldiOSmacOS/tasks/0012-lyrics-active-line-pill.md`, `melogoldLinux/tasks/0003-lyrics-active-line-pill.md`.
Образец — Windows (`melogoldWindows/src/Melogold.App/Controls/SyncedLyricsView.cs`, сделано).

## 1. Что нужно пользователю

Пользователь о тексте на Windows: «мне очень сильно понравилась твоя реализация лирики с этим блоком посередине,
который подстраивается под размер текста, который в данный момент играет». Попросил записать во все остальные
репозитории, что должно быть так.

Сейчас на Android текущая строка отмечена только яркостью (прошедшие 0.35, будущие 0.6), подложки нет.

## 2. Как должно быть (одинаково на всех клиентах)

- **Подложка** — скруглённый прямоугольник под текущей строкой. Размер — **по тексту строки**, а не на всю ширину:
  ширина самой длинной строки переноса плюс поля, высота — вся строка вместе с подпевкой и переводом под ней.
  - Поля: 16 × 10 при базовом размере текста 28; скругление 12. Всё масштабируется с размером текста
    (`fontSize / 28`).
  - Строка второй стороны дуэта стоит у правого края — подложка тоже.
- **Переезд:** на следующую строку подложка **переезжает и меняет размер** пружиной (Windows: затухание 0.78, период
  70 мс — быстро, с едва заметным дотягиванием), а не исчезает и появляется. Если строка сдвинулась после раскладки
  (поворот, смена размера текста, прокрутка), подложка догоняет её.
- **Без текущей строки** (до первой строки, проигрыш с точками) подложка гаснет за 200 мс; с новой строкой —
  проявляется на её месте без переезда.
- **Цвет:** цвет по обложке — `secondaryContainer` схемы, построенной из обложки (как у фона «Сейчас играет»); без
  цвета обложки — белый 16 % на тёмном, чёрный 8 % на светлом.
- **Нажатие** на строку по-прежнему перематывает; подложка нажатия не перехватывает.
- **Меньше движения** (системная настройка): подложка встаёт на место сразу, без пружины.
- Яркость строк прежняя: текущая 1, прошедшие 0.35, будущие 0.6; слова загораются, как сейчас.

## 3. Android

- `ui/screens/player/modern/SyncedLyricsView.kt`: подложку рисовать **один раз** за списком (`drawBehind` у контейнера
  `LazyColumn`), а не фоном каждой строки — иначе не будет переезда. Прямоугольник текущей строки — из
  `onGloballyPositioned` строки (границы текста, `Column` строки), в координатах контейнера.
- Анимация — `Animatable(Rect)` / `animateRectAsState` с `spring(dampingRatio = 0.78f, stiffness ≈ 8000f)`;
  `reduceMotion` → `snap()`. Прозрачность — `tween(200)`.
- Ширина строки — по фактическому тексту: у `Text` строки не `fillMaxWidth`, а `wrapContentWidth` с выравниванием
  по стороне; клик — по всей ширине строки, как сейчас.

## 3а. Заодно: фон «Сейчас играет» не позже текста

На Windows фон по обложке иногда появлялся позже строк текста, и это выглядело странно (пользователь, 2026-09-26).
Если фон на Android тоже считается по обложке: цвет считается при смене трека, даже когда «Сейчас играет» закрыто, и к
открытию уже готов; пока не готов — цвета темы, а не прозрачность; готовый цвет наплывает за 0,3 с.

## 4. Проверка

- Скриншоты «Сейчас играет» → «Текст»: короткая строка (подложка узкая), длинная с переносом (по самой длинной
  строке), строка с подпевкой, дуэт справа, проигрыш (подложки нет).
- Видео или несколько кадров переезда на следующую строку.
