# Кадр видео: середина в квадрате, целиком в «Сейчас играет»

Статус: сделано

Те же задания: `melogoldWindows/tasks/0007-video-frames.md` (сделано: середина кадра — Windows 0.1.4, срезка полей — 0.1.5), Apple — `melogoldiOSmacOS/tasks/0008-video-frames.md`.

## 1. Что нужно пользователю

Пользователь включил «Never Gonna Give You Up» (`dQw4w9WgXcQ`) в Windows. В квадратной обложке остались надпись и плечо Рика, а всё справа, с лицом, было вырезано. Его слова: если бы брали середину или честно показывали прямоугольник, было бы честно.

Второе замечание: у видео-«статики» («GORILLA GLUE, LIL NAKUR – БАРМАЛЕЙ (Сингл, 2026)», `LLhpBVFh2Zg`) обложка сингла квадратная, а стоит в кадре 16:9 с чёрными полями по бокам. В «Сейчас играет» она показывалась прямоугольником с полями. Его слова: чёрные полосы нужно обрезать.

## 2. Решение (одинаково на всех клиентах)

- **Квадрат:** у кадра видео 16:9 берётся центральный квадрат, а не левый или верхний край. Это касается:
  - строк, карточек, мини-плеера, очереди и шапок экранов;
  - уведомления, экрана блокировки и виджета;
  - цвета по обложке.
- **«Сейчас играет»:**
  - у кадра видео (`i.ytimg.com/vi/<id>/…`) большая обложка показывает кадр целиком, прямоугольником 16:9: ширина как у квадрата, высота — 9/16 ширины;
  - у песен (`lh3` и `yt3`) обложка остаётся квадратом;
  - маленькая обложка в заголовке режима «Текст» — квадрат с серединой кадра.
- **Без чёрных полос:**
  - до 360 px — `mqdefault.jpg` (320×180), крупнее — `hq720.jpg` (1280×720);
  - `hqdefault` и `sddefault` — это 4:3 с полосами сверху и снизу. Если без них не обойтись, полосы срезаются (REWRITE §4.8.2).
- **Резкость:** в квадрате кадр видео декодируется по высоте, то есть по короткой стороне.
- **Чёрные поля срезаются по пикселям.** Кадр видео (`i.ytimg.com/vi/<id>/…`) бывает с полями: обложка сингла в кадре 16:9 — поля по бокам, превью 4:3 — сверху и снизу. Поля срезаются, когда картинка попадает в кэш, поэтому без полей она показывается везде: в строках, в плеере и в цвете по обложке.
  - **Правило, как `FrameBars` у Windows** (`melogoldWindows/src/Melogold.Core/Music/FrameBars.cs`, тесты `FrameBarsTests`):
    - строка или столбец — поле, если у 98 % пикселей каждый канал ≤ 28;
    - поля срезаются, только если вместе они не меньше 3 % стороны;
    - поля одинаковые с двух сторон: разница не больше 3 % стороны;
    - после обрезки остаётся не меньше 40 % стороны.
  - **Тёмная сцена самого видео полем не считается:** тёмен обычно один край, а не оба поровну.
  - Цвет по обложке уже срезает поля мягче (`ArtworkColorScheme.kt` у Android). Картинке нужно правило строже.
- **Форма в «Сейчас играет»** зависит от картинки после обрезки, а не от адреса:
  - шире 1,2:1 — прямоугольник 16:9;
  - иначе — квадрат. Обложка сингла из видео-«статики» становится квадратом.

## 3. Android

- **Строки и мини-плеер:** `ContentScale.Crop` с выравниванием по умолчанию (`Alignment.Center`) уже режет по центру. Проверь, что ни у одной обложки не задано другое выравнивание.
- **`PlayerArtwork`** (`ui/screens/player/modern/NowPlayingParts.kt`):
  - сейчас это всегда квадрат `size(size)`;
  - у кадра видео нужен `size(width = size, height = size * 9 / 16)`;
  - общий элемент перехода между обложкой и заголовком режима «Текст» должен учитывать эту высоту.
- **`String.thumbnail`** (`utils/Utils.kt`):
  - кадр видео крупнее 360 px сейчас уходит с исходным адресом;
  - если это `hqdefault.jpg` или `sddefault.jpg` без обрезающих `sqp`, в большой обложке будут видны полосы. Проверь на реальных ответах YouTube Music и WEB;
  - подставляй `hq720.jpg`, как Windows и Apple (`Thumbnails.sized`), а при 404 — `hqdefault` со срезанными полосами.
- **Уведомление и экран блокировки:** картинка из `BitmapLoader` — центральный квадрат без полос.

- **Кэш картинок:** поля срезает `Transformation` Coil (или свой `Interceptor`) для адресов `i.ytimg.com/vi/`, по правилу выше. Тот же битмап уходит в уведомление и виджет.

**Сделано:**
- `String.thumbnail` (`utils/Utils.kt`): кадр видео по id, без `sqp`: до 360 px — `mqdefault`, крупнее — `hq720`; `vi_webp` и `//` тоже. `squareThumbnail` выбирает кадр для квадрата по высоте (сторона × 16/9) — им пользуются `Artwork`, шапка «Текста», уведомление, цвет и обложка экспорта.
- `VideoFrames` (`utils/VideoFrames.kt`, интерсептор `ImageLoader`): каждому кадру `i.ytimg.com/vi/` добавляет `FrameBarsCrop` — `Transformation` с правилом `FrameBars`, как у Windows (ключ кэша с версией `frame_bars_v1`). Поэтому кадр без полей везде: в строках, плеере, уведомлении, виджете и цвете. На 404 у `hq720` грузится `hqdefault`; видео без `hq720` запоминаются до перезапуска, а без сети берётся `hqdefault` из дискового кэша.
- `PlayerArtwork`: форма — по картинке после обрезки, а не по адресу: шире 1,2:1 — высота 9/16 ширины, иначе квадрат (он же до первой картинки и при ошибке). Новая картинка держит прошлую форму, пока грузится, а формы запоминаются — снова открытый плеер не прыгает. При ошибке воспроизведения — квадрат, чтобы карточка ошибки помещалась. Название держит свой отступ под обложкой и поднимается вместе с ней. Общий элемент «art» берёт реальные границы, переход в квадрат шапки их учитывает.
- `BitmapProvider` и цвет по обложке берут `centerSquare()`.
- Выравнивание: все обложки — `ContentScale.Crop` с `Alignment.Center` по умолчанию, другого нет.
- Тесты: `ThumbnailTest`, `VideoFramesTest` (случаи `FrameBarsTests`; обложка «Бармалея» в кадре 1280×720 → 720×720; запасной `hqdefault` через настоящий `ImageLoader`, в том числе без сети из дискового кэша; середина квадрата).
- Эмулятор: `LLhpBVFh2Zg` в «Сейчас играет» — квадратная обложка без полей, `dQw4w9WgXcQ` — кадр 16:9 целиком.

## 4. Проверка

- **Правило полей:** те же случаи, что `FrameBarsTests` у Windows — квадрат в 16:9, превью 4:3, кадр без полей, тёмная сцена с одной стороны, почти чёрный кадр, тонкая кромка, шум JPEG в поле.
- **`LLhpBVFh2Zg` («Бармалей»):** в «Сейчас играет» квадратная обложка без чёрных полей.

- **Тест `thumbnail()`:** `…/hqdefault.jpg` при 720 px даёт `hq720.jpg`, при 120 px — `mqdefault.jpg`.
- **Эмулятор, `dQw4w9WgXcQ`:**
  - в строке и мини-плеере лицо Рика по центру;
  - в «Сейчас играет» кадр целиком: слева надпись «RICK ASTLEY», справа лицо;
  - в уведомлении центральный квадрат без полос.
