# Своё название, исполнитель и альбом трека

Статус: открыто — ждёт сервер (`melogoldServer/tasks/0001-track-overrides.md`: контракт ещё не утверждён)

Общая часть (что нужно пользователю, как должно быть, синк, тексты) — `melogoldWindows/tasks/0011-track-overrides.md`.
Те же задания: `melogoldiOSmacOS/tasks/0014-track-overrides.md`, `melogoldLinux/tasks/0005-track-overrides.md`.

Коротко: собранный из разрозненных видео YouTube альбом (обход цензуры) должен выглядеть одним альбомом на всех
устройствах. Решение пользователя (2026-09-26): на сервере только текст — название, исполнитель, альбом; обложки и
файлы не храним.

## Android

- Room: таблица правок (`videoId` PK, `title`, `artistsText`, `albumTitle`, `updatedAt`) и миграция; правка
  применяется в одном месте при показе `Song` (строки, плеер, мини-плеер, медиасессия Media3, «Сохранить файлом»).
- Меню трека → «Изменить сведения…»; режим выделения (`0011`) → «Указать альбом…».
- `LyricsFetcher`: поиск LrcLib сначала по правленым названию и исполнителю.
- `sync/LibrarySync`: op `track.override.set` и разбор `overrides`, только если вид есть в `features.sync.kinds`.
- Копия библиотеки (`0002`, общий формат) — правки отдельным полем.

## Проверка

Юнит-тесты применения правки и op; живой сервер (временный аккаунт): правка с Windows видна на Android и обратно;
скриншоты окна «Сведения о треке» и плейлиста-альбома.
