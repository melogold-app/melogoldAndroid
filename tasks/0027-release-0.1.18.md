Статус: открыто. `main` готов 07.10.2026: версия 0.1.18 в `gradle.properties`, заметки `release-notes/0.1.18.{ru,en}.md`.
В выпуске задания 0024 (обрыв на первом мегабайте), 0025 (нет сети — трек ждёт), 0026 (перенос на другое устройство с
той же секунды). Unit-тесты `NetworkWaitTest`, `DirectStreamsTest`, `RemoteCommandsTest` проходят. На ThinkPad

## Сделать — на Маке (ключ подписи есть только там)

1. Переложить ключ подписи в общий приватный сейф секретов, чтобы Android выпускала и вторая машина.
   Порядок и команда — в приватных заметках агента (пункт «ОТКРЫТО» про ключ Melogold). В этот публичный
   репозиторий ключ, пароли и пути к ним не попадают никогда, даже зашифрованными.
2. Выпустить: `git switch main && git pull --ff-only && scripts/release.sh --publish`.

Подпись должна совпасть с 0.1.17 (SHA-256 сертификата `1735ecb3…bf33`): иначе обновление не встанет поверх
установленного приложения.
