# Действия с выделенными треками: скачать, в Избранное, собрать плейлист

Статус: открыто

Те же задания: `melogoldiOSmacOS/tasks/0013-selection-actions.md`, `melogoldLinux/tasks/0004-selection-actions.md`.
Образец — Windows (сделано, Windows 0.1.10: `Controls/SelectionBar.cs`, `Services/TrackActions.cs`).

## 1. Что нужно пользователю

«Нужно сделать массовые действия: выделить все или конкретные элементы и скачать их, добавить в Избранное или создать
с ними плейлист». И зачем: Melogold — обход ограничений и цензуры в музыке. Альбом, который сначала зацензурировали, а
потом удалили, лежит на YouTube разными видео от разных людей, с разными обложками, а не одним альбомом. Пользователь
находит эти треки поштучно и собирает из них альбом-плейлист.

## 2. Решение (одинаково на всех клиентах)

- **Выделение** в любом списке треков (Избранное, «Все треки», история, плейлист, альбом, поиск, «Скачанное»):
  - на телефоне — долгое нажатие по треку включает режим выделения, дальше касания отмечают и снимают отметку;
    «Назад» или ✕ выходят из режима;
  - на компьютере — как везде в системе: Ctrl+щелчок, Shift+щелчок, Ctrl+A, Esc снимает выделение.
- **Панель действий** появляется, пока есть выделение (на компьютере — от двух треков: один трек — обычное меню):

  | Действие | Русский | English | Что делает |
  |---|---|---|---|
  | счётчик | Выбрано: {0} | {0} selected | — |
  | ▶ | Слушать | Play | выделенные **в порядке списка** — новой очередью |
  | очередь | В конец очереди | Add to queue | в конец очереди; уведомление «В конец очереди: N треков» |
  | ♡ | В Избранное | Add to Favorites | всем сразу, одной записью; «В Избранное: N треков» |
  | + | Добавить в плейлист… | Add to playlist… | обычный выбор плейлиста |
  | новый | Новый плейлист… | New playlist… | диалог названия; **по умолчанию — название альбома**, если у всех выделенных он один; «Плейлист «X»: N треков · Открыть» |
  | ↓ | Скачать | Download | скачанные, скачивающиеся и трансляции пропускаются; «Скачивается: N треков» или «Выделенное уже скачано» |
  | | Выбрать все | Select all | все треки списка |
  | ✕ | Снять выделение | Clear selection | — |

  В узком экране лишнее уходит в «⋮», как у обычной панели действий.
- Правый щелчок (компьютер) по выделенному — те же действия меню.
- Числа — с формами множественного числа («1 трек», «2 трека», «5 треков»).

Дальше (отдельно, ждёт решения по серверу): у трека в плейлисте можно будет поменять название, альбом и обложку, чтобы
собранный альбом выглядел одним альбомом на всех устройствах.

## 3. Android

- Списки треков — общий компонент строк (Compose `LazyColumn`): состояние выделения `Set<videoId>` на экран, режим
  выделения — `TopAppBar` с счётчиком, «Выбрать все» и ✕ вместо заголовка; действия — нижняя панель (или те же кнопки
  в `TopAppBar` + «⋮»).
- Отмеченная строка — цвет `secondaryContainer` и галочка вместо обложки (как выделение в «Файлах» Google).
- `BackHandler` выходит из режима выделения.
- ♡ всем сразу — одна транзакция `Database` и одна запись в синк (`LibrarySync`), а не N.
- «Скачать» — существующее «Скачать» (`0001`/`0007`), по одному на трек.

## 4. Проверка

- Юнит-тесты: название по умолчанию (общий альбом / разные альбомы / без альбома); «Скачать» пропускает скачанные и
  трансляции; порядок «Слушать» — порядок списка, а не порядок нажатий.
- Скриншоты: режим выделения в Избранном (3 отмечено), диалог «Новый плейлист» с названием альбома, уведомление после
  «Скачать».
