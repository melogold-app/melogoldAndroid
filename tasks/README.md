# Задания

Всё, что нужно сделать в Android-клиенте, лежит здесь: одно задание — один файл `NNNN-название.md` с тем, что нужно пользователю, решением и проверкой. Те же задания для Windows — в `melogoldWindows/tasks/`, чтобы клиенты вели себя одинаково. Большая спецификация — `docs/REWRITE.md`.

## Как работать

1. В начале каждой сессии прочитай этот файл и открытые задания.
2. Выполняй их по номерам, сразу. Каждое задание — срез: сборка и тесты → staging на эмулятор → скриншот → коммит → push.
3. Берёшь задание — статус «в работе»; сделал — «сделано (<коммит>)», в том же коммите, что и работа.
4. Если в задании что-то не решено, спроси пользователя, прежде чем делать.

Статусы: `открыто` · `в работе` · `сделано (<коммит>)`.
