- Импорт из ViTune и ViMusic: Библиотека › «Импорт из ViTune или ViMusic» или Настройки › База данных. Копия добавляется к библиотеке: треки, вся история прослушиваний, Избранное, плейлисты, тексты, сохранённые альбомы и исполнители. Ничего не удаляется, повторный импорт не задваивает историю. При входе в аккаунт история уходит на другие устройства через сервер.
- Музыка всегда кэшируется, по умолчанию до 4 ГБ. Когда место кончается, уходят треки, которые дольше всех не слушали.
- Трек, целиком лежащий в кэше, играет без сети и отмечен значком «есть без сети». В «Скачанном» есть группа «В кэше».
- Кэш лежит в Android/data и не удаляется как мусор. Старый кэш при обновлении очищается один раз.
- В режиме текста касание внизу экрана возвращает кнопки управления, а не перематывает.
- В меню по долгому нажатию на мини-плеер есть «В Избранное».
- Заставка при запуске в системных цветах, а не тёмно-синяя.
