- Sign in by code: on a new device tap "Sign in with a code" and it shows a code. On a phone where you are already signed in, open Account › Add device, enter the code and pick the number the new device shows. No password needed.
- It also works the other way round: "Add device" › "Show a code for a new device", and on the new device "Sign in with a code" › "I have a code from another device".
