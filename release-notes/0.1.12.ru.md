- Вход по коду: на новом устройстве нажмите «Войти по коду» — оно покажет код. На телефоне, где вы уже вошли, откройте Аккаунт › Добавить устройство, введите код и выберите число, которое показывает новое устройство. Пароль вводить не нужно.
- Можно и наоборот: «Добавить устройство» › «Показать код для нового устройства», а на новом — «Войти по коду» › «У меня есть код с другого устройства».
