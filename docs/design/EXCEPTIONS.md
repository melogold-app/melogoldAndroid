# Исключения Melogold: Android

Реестр по `docs/DESIGN-DOCTRINE.md` §3. Нет строки — нет исключения: всё остальное делается системными компонентами.
Общие исключения уже внесены; поля «От какого правила» и «Что сохраняем» уточняются при аудите (`tasks/0020-design-doctrine-audit.md`).
